# Remix of Опліс: Святкова Кулінарія

Створи сучасний односторінковий лендинг для замовлення святкових страв та кулінарії від мережі супермаркетів Наш Край. Використовуй фірмові кольори бренду: зелений, помаранчевий та білий. Сайт повинен мати такі блоки: Хедер з логотипом Наш Край та навігацією, Хіро-секція з великим заголовком Святкуйте без турбот — кулінарія Наш Край для вашого свята та кнопкою Скласти меню, блок Про послугу (деталі про свіжість, шеф-кухарів та швидкість), Блок з картками страв (нарізки, гарячі страви, фуршетні закуски, торти на замовлення) з цінами, блок з відгуками клієнтів, блок з контактами та велику віджет-кнопку у правому кутку екрану для запуску голосового ШІ-асистента
